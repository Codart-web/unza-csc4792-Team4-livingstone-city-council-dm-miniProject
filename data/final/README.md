# Final Datasets — TRACKED IN GIT

This directory holds the project's deliverable datasets, ready for
Kaggle publication.

## Conventions

- File format: CSV
- Field separator: `|` (pipe)
- Filename pattern: `db-unza26-csc4792-[DESCRIPTION].csv`
- Encoding: UTF-8 (no BOM)
- Every column documented in `docs/data_dictionary/`
- Every dataset supported by entries in
  `docs/source_register/source_register.csv`

Do not commit partially-cleaned or unvalidated CSVs here. Only
datasets that have passed Phase 6 validation.

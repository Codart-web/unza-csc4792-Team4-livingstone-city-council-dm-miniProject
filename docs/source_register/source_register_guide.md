# Source Register Guide

Every source used by the project must be registered before its data is incorporated into a final dataset.

## Required Fields

- `source_id`
- `source_title`
- `source_type`
- `year`
- `data_domain`
- `url`
- `retrieval_date`
- `responsible_member`
- `extraction_method`
- `status`
- `notes`

## Source Types

Examples:

- website
- webpage
- PDF
- report
- budget
- financial statement
- spreadsheet
- publication
- minutes
- newsletter

## Status Values

Suggested values:

- discovered
- verified
- acquired
- extracted
- rejected
- inaccessible

## Rule

A source is not automatically valid merely because it exists online.

The team must establish:

1. what the source is;
2. who published it;
3. what period it represents;
4. what information it contains;
5. how it will contribute to the dataset.

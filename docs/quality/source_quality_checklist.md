# Source Quality Checklist

For each candidate source:

- [ ] Official Livingstone City Council source
- [ ] Relevant to the assignment
- [ ] Source identity established
- [ ] Date/year established where possible
- [ ] URL recorded
- [ ] Retrieval date recorded
- [ ] Responsible member assigned
- [ ] Extraction method identified
- [ ] Data domain identified
- [ ] Source evidence preserved
- [ ] Potential duplication considered
- [ ] Potential conflicts documented
